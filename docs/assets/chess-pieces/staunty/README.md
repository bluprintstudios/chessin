# Chess piece assets

The twelve SVGs supplied by the project owner strongly appear to match the Lichess `lila/public/piece/staunty` set. The local files were not byte-for-byte compared against all upstream files. Lichess credits the Staunty set to `sadsnake1` under CC BY-NC-SA 4.0.

That license requires attribution, prohibits commercial use, and requires ShareAlike for adaptations. This app is planned to include a `$9.99` one-time purchase, so these pieces are **not cleared for commercial distribution** unless separate permission is obtained from the rights holder. Their source SVGs remain here for reference only; they are excluded from Android runtime assets.
