# Release Copy Guide

*This document contains the approved, plain-language text intended for the app's UI screens. It accurately reflects the app's technical architecture, local-first nature, and billing structure.*

## 1. Onboarding Screen
**Headline:** Your review stays yours
**Body:** Import a completed game, analyze it on-device, and learn from the moves that mattered.
**Privacy Notice:** Local by default. AI coaching is optional and sends only the evidence needed for your question.
**Disclaimer:** No account required • No live-game help • Independent and unaffiliated

## 2. Game Library Screen
**Empty State Body:** Your imported games will appear here. Choose Import PGN to add a completed game.
**Import Notice:** Your games stay on this device.
**Disclaimer:** Independent and unaffiliated with Chess.com.

## 3. Coach Screen
**Headline:** Talk through the position
**Body:** Ask about a completed game. Explanations use the selected position and its Stockfish lines.
**Data Transmission Consent:** 
- *Checkbox Label:* Allow this position to be sent for an AI explanation.
- *Details:* Only the selected FEN, your question, the played move, and supplied engine lines are included. The full PGN and account name are not sent.
**Fair Use Notice:** Preview counter: [X] / [Y]. Final production allowance and provider terms are pending.
**Disclaimer:** Chessin' is independent and unaffiliated with Chess.com. AI explanations are optional; local replay remains available.

## 4. Membership / Paywall Screen
**Headline:** More room to learn
**Body:** One payment for permanent access to the app's premium features. No subscription.
**Features list:**
- ✓ Local games and reviews stay available on this device
- ✓ Restore your purchase with the same Google Play account
**AI Coach Terms:** AI explanations use an online service and have a separate fair-use allowance. The final allowance, provider data terms, and monthly service limits are still being reviewed. Checkout is disabled until those details are approved and shown here.

## 5. Settings Screen
**Games Data:** PGN imports and review data are stored on this device and are not included in Android cloud or device-transfer backups. You can use the library and replay without a network connection.
**Legal Notice:** Chessin' does not connect to game accounts. Only import game files you have the right to use; check the source's terms before using its exports in a paid app.
**Delete Data:** This will permanently delete all imported PGN games, cached engine analysis, and local preferences from this device.
